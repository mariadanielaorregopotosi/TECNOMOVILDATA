# TecnoMovil Data

## Descripción

Proyecto académico desarrollado en Java para aplicar programación funcional al procesamiento de registros simulados de un sistema de transporte urbano.

## Funcionalidades

- Cálculo de afluencia por estación.
- Identificación de horas pico.
- Conteo y clasificación de rutas utilizadas.
- Patrones de viaje por usuario.
- Estimación del tiempo promedio entre estaciones.
- Detección de rutas críticas mediante un umbral simulado.

## Requisitos

- JDK 17 o superior.
- IDE compatible con Java o terminal de comandos.

## Ejecución

Compilar:

`javac TecnoMovilData.java`

Ejecutar:

`java TecnoMovilData`

## Conceptos aplicados

Java Streams, expresiones lambda, inmutabilidad, funciones de orden superior, composición y procesamiento declarativo.
